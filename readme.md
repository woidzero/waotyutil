### woid's aoty utility

</br>

Quick add new releases from Apple Music, Bandcamp, Deezer, Discogs, MusicBrainz, Qobuz, SoundCloud, Spotify, and TIDAL + other useful features for <a href="https://aoty.org">aoty.org</a> contributors.

</div>

### features

- auto-fill new release info from Bandcamp, Deezer, Discogs, MusicBrainz, Qobuz, SoundCloud, Apple Music, Spotify, and TIDAL.
- automatic conversion of the cover format to the set standards
- set cover from a direct link to the image

### installation

> 1. install <a href="https://www.tampermonkey.net/">tampermonkey</a> / <a href="https://www.greasespot.net/">greasemonkey</a> / other userscript manager.
> 2. add <a href="https://by.woid.im/waotyutil.user.js">waotyutil.user.js</a>.
> 3. done.

### settings

> open settings from the website header to adjust image dimensions, JPEG quality, and the maximum cover file size. settings are saved in your browser local storage.

### build from source

> ```bash
> git clone https://github.com/woidzero/waotyutil.git
>
> cd waotyutil
>
> bun i // or npm i
>
> bun run build
> ```
